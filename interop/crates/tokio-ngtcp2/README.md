# tokio-ngtcp2

Tokio async runtime integration for the local ngtcp2/nghttp3 wrapper.

## Overview

Provides wrappers for using the ngtcp2/nghttp3 wrapper with the Tokio async runtime.

## Features

- Tokio async runtime integration.
- Async I/O support.

## Dependencies

- `ngtcp2` - ngtcp2/nghttp3 wrapper.
- `tokio` - async runtime.
